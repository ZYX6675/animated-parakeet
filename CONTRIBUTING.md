# Contributing

Read docs/CLEANROOM_POLICY.md first. Every pull request that touches compatibility code must say:

1. Which specification or public document it implements.
2. That the author has not seen proprietary source, leaked source, or decompiled/disassembled output
   for that component.
3. How it was tested (unit tests, behavior comparison, or a recorded app test run).

Recipes need evidence before a status of `works` or `partial`.
